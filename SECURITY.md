# Security Policy

## Supported versions

Security fixes are developed against the latest released version and the
`main` branch. Older releases may not receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or discussion.
Use [GitHub's private vulnerability reporting](https://github.com/codefensory/climier/security/advisories/new)
to contact the maintainers securely.

Include, when available:

- the affected version or commit;
- a clear description of the impact;
- reproduction steps or a proof of concept; and
- any suggested mitigation.

We will acknowledge a report as soon as practical, investigate it, and
coordinate a fix and disclosure timeline with the reporter.

## Disclosure

Please allow time for a fix and release before sharing details publicly. We will
credit reporters who want attribution in the security advisory.
