# Climier

Climier is a JSON-first coordination tool for organizing work across agents, sessions, and humans. It keeps tasks, decisions, dependencies, and shared knowledge in a durable project graph so teams can see what is ready, what is blocked, and how work moves through review.

## Explore Climier

- [Install Climier](/docs/getting-started/install) to set up the CLI.
- Learn how [tasks and dependencies](/docs/concepts/tasks) work.
- Follow the guide to [coordinate multiple agents](/docs/guides/multi-agent).
- Consult the [CLI reference](/docs/reference/cli) for command details.
