---
title: Older or incomplete state
description: Recovery guidance for state files outside the canonical schema.
---

SQLite is the canonical runtime store. The legacy JSON schema-1 importer remains
available only through the explicit `climier state migrate --as <agent> --yes`
command; `climier state export` writes schema-1 JSON for transfer or backup.
Migration preserves a verified copy of its JSON source.

If migration reports an incomplete or otherwise non-canonical JSON state:

1. Stop every writer for that project, including the local UI and remote server.
2. Preserve the complete project directory and its backups without editing or
   deleting files.
3. Do not use `init --force`; it resets data and does not convert old state.
4. Restore a verified canonical backup, or contact the maintainer for recovery
   guidance. Do not point an older binary at a migrated project; old releases
   can misclassify canonical state and offer a destructive reset.

For an upgrade that requires a different state schema, follow only the
release-specific supported transition plan. Do not upgrade writers until the
required state transition and rollback procedure are clear. See the [remote
server runbook](/docs/reference/self-hosting) for service shutdown and backup
practices.
